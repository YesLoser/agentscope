# AgentScope 二开 · 知识模块拆解与学习路线

> 目标：二开 AgentScope 做成「可组装垂直领域 Agent 的 AI 平台」。
> 原则：从你熟悉的（Java/关系型数据库/Web 分层）切入，逐个模块打通，不追求一次看懂全貌。

每个模块按四栏理解：**是什么 / 对应你熟悉的 Java 概念 / 先修知识 / 完成标志**。

---

## 模块 0：开发环境与 Python 基础（已基本完成 ✅）

- 是什么：`.venv` 虚拟环境、`async/await`、`uv` 包管理、`src/` 布局。
- 对应 Java：Maven/Gradle 项目结构、JVM 环境。
- 完成标志：能激活 venv、能跑起后端和前端、知道 `async def`/`await` 为什么这么写。
- 状态：已跑通（2026-10-23）。

## 模块 1：存储与数据持久化（← 当前这一步）

- 是什么：`StorageBase` 抽象层；`RedisStorage`（键值）和 `AsyncSQLAlchemyStorage`（关系型表 + Alembic 迁移）两种后端；数据按 `user_id` 隔离。
- 对应 Java：DAO 层 / MyBatis / JPA、数据库表设计。
- 先修知识：了解 SQLAlchemy 基本概念（Engine/Session/ORM 表）、Alembic 迁移。
- 完成标志：把默认 Redis 换成 MySQL，能在 MySQL 里看到 `agent`/`session`/`message` 等表和数据。

## 模块 2：Web 服务层（FastAPI）

- 是什么：FastAPI 应用、路由（`_router/`）、依赖注入 `Depends()`、请求头 `X-User-ID` 做身份、多租户隔离。
- 对应 Java：Spring MVC / Controller / Filter / Interceptor。
- 先修知识：HTTP 基础、Python 装饰器（`@app.get`）、异步路由。
- 完成标志：能读懂 `create_app` 怎么注册路由，能自己加一个接口。

## 模块 3：消息与事件流

- 是什么：`Msg`（消息类型）、`Event`（事件总线）、`message_bus`（跨会话消息）、SSE 流式输出。
- 对应 Java：事件机制 / 消息队列（概念上类似）。
- 完成标志：理解一条消息从模型到前端是怎么"流"出来的。

## 模块 4：模型与凭证（AI 核心之一）

- 是什么：`Model`（聊天/嵌入/TTS）、`Credential`（API Key）、各 provider（OpenAI/DeepSeek/DashScope…）、模型卡 YAML、`Formatter`（消息↔API 格式）。
- 对应 Java：第三方 SDK 封装 / 适配器模式。
- 先修知识：LLM 的 API 调用、`tool calling`（工具调用）、`thinking/reasoning`（推理）。
- 完成标志：能看懂一个 provider（比如 DeepSeek）从凭证→模型→请求→解析响应的完整链路。

## 模块 5：Agent 核心循环（AI 核心之二）

- 是什么：Agent 的「想 → 调工具 → 看结果 → 继续」循环（ReAct 模式）、中间件（middleware）、结构化输出。
- 先修知识：先搞懂模块 4 的 tool calling。
- 完成标志：能解释 agent 为什么能"自主干活"，并知道中间件在哪几个点介入。

## 模块 6：工具 / MCP / Skill（AI 核心之三）

- 是什么：Python 函数怎么变成工具（`Toolkit`）、MCP 协议（外部工具服务器）、Skill（技能包）。
- 对应 Java：接口 + 实现、插件机制。
- 完成标志：能自己写一个自定义工具，并在 agent 里调用成功。

## 模块 7：权限 / 多租户 / 资源分享

- 是什么：`permission`（工具级权限 + 人机协同 HITL）、`resource_access_policy`（跨用户分享/组织）。
- 对应 Java：RBAC / 权限体系 / 多租户 SaaS。
- 完成标志：能说清"用户-租户-资源-权限"四者关系，并知道账户体系（登录/SSO）是要二开补的。

## 模块 8：知识库 RAG

- 是什么：文档解析 → 切分（chunker）→ 向量化 → 检索（vector store）。
- 对应 Java：搜索引擎/检索（概念上）。
- 完成标志：能上传一个文档，让 agent 基于它回答问题。

## 模块 9：渠道接入（可选）

- 是什么：飞书 / Discord / 钉钉机器人，把 agent 接到 IM 平台。
- 对应 Java：第三方开放平台对接。
- 完成标志：让 agent 在飞书群里回复消息（需要相应账号/凭证）。

## 模块 10：前端 web_ui（可选）

- 是什么：React + Vite 的前端，`frontend/src/pages` 对应各个后台页面。
- 对应 Java：前端/模板（如果你做过前后端分离的话）。
- 完成标志：能改一个页面、加一个字段。

---

## 推荐推进顺序

1 → 2 → 4 → 5 → 6 → 7 → 8 →（9、10 按需）

其中 **4→5→6 是 AI 的核心**，也是你理论有、但缺实战的部分，重点打穿。
